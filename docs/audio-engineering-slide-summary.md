# 音声工学 スライドまとめと予想問題方針

## 第01回 音声と言語
- 音声は発声器官で発した音、言語は思想・感情・意志を伝える記号体系。
- 音声工学ではTTSとSTTを扱うため、音声言語と文字言語の理解が必要。
- 言語は語族で分類され、日本語は系統不明の孤立した言語。
- 日本語は話者数が世界第9位で、音声言語としては特殊でないが文字体系は複雑。
- 出題化: 語族、日本語の特徴、文字体系、TTS/STT。

## 第02回 音素の分類
- 声道は喉頭腔・咽頭腔・口腔・鼻腔で構成される。
- 音の発生原因は物体の振動、空気の乱流、空気の膨張・収縮。
- 母音は声帯振動を音源とし顕著な狭めを持たない言語音。
- 音素、音素表記、IPA、異音、音節、モーラが重要。
- 出題化: 声道の構成、母音・子音、/h/の異音、音節とモーラ。

## 第03回 音声生成の生理1
- 喉頭の骨・軟骨・筋肉、声帯と声門の構造を扱う。
- 覚える対象は舌骨、甲状軟骨、輪状軟骨、披裂軟骨。
- 後輪状披裂筋は声門開放、外側輪状披裂筋・横披裂筋は声門閉鎖。
- 輪状甲状筋は声帯を伸ばし、声帯筋・甲状披裂筋は声帯を縮める。
- 出題化: 喉頭構造、声門、筋肉と作用、ピッチの物理量。

## 第04回 音声生成の生理2
- 声道、肺・気管・呼吸、舌骨、軟口蓋、口唇、鼻腔、舌を扱う。
- ヒトの声道は口腔から咽頭腔にかけて90度に屈曲する。
- 安静呼吸、胸式深呼吸、腹式深呼吸で働く筋が異なる。
- 発話時には軟口蓋が挙上し、鼻腔への入り口を閉鎖する。
- 出題化: 呼吸筋、肺の左右差、軟口蓋、鼻腔・副鼻腔。

## 第05回 音声の音響的性質と分析
- 音の3属性は大きさ・高さ・音色で、音声では呼気圧・声帯振動・声道形状と関係する。
- 音圧レベルは最小可聴音圧値を基準とするdB値で表す。
- ピッチの主な物理量は声帯振動の基本周波数。
- 自己相関法、AMDF法、ケプストラム、LPCなどが分析方法として扱われる。
- 出題化: dB、最小可聴音圧、会話音声の音圧レベル、ピッチ抽出法。

## 第06回 音声の知覚
- 母音の知覚手がかりはフォルマントであり、F1・F2が日本語5母音の弁別に重要。
- F1は舌の上下、F2は舌の前後と対応する。
- /s/と/ʃ/はスペクトルピークの周波数帯が異なる。
- 有声摩擦音では摩擦音スペクトルに声帯振動の倍音や声道共鳴が重畳する。
- 出題化: フォルマント、母音5角形、摩擦音、VOT、カテゴリ知覚。

## 中間テストから見た出題傾向
- 空欄補充の対応問題が多い。
- 用語を短答で答える問題が多い。
- 数値・単位・記号をそのまま答える問題が出る。
- 筋肉名と作用、分析法と性質などの組み合わせ問題が出る。
- 予想問題はこの傾向に合わせ、matching / text / single / multiple を混在させた。
