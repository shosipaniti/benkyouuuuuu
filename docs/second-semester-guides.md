# 後期予想問題の詳しい解説

データベース183問とデータマイニング167問、計350問から詳しい解説を開ける。問題に対応するテーマを初期表示し、他のテーマへも移動できる。問題文と正解は変更しない。

講義の第1〜5回と演習を基礎に、用語の区別、手順を追った例、SQLやRコード、間違えやすい条件を収録した。参照ページはPDF先頭を1とした番号。

## 計算例の検証

SQL 9例をSQLite、R 11例を実Rで実行した。実行に必要な練習データは既存問題のfixtureまたは各例の検証用setupから作る。コードをアプリの閲覧時に実行する機能ではない。

SQLiteのNULL、結合、集計の仕様とRの分散、k-means、主成分分析の出力も公式資料を補助に確認した。

- https://www.sqlite.org/lang_select.html
- https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.html
- https://stat.ethz.ch/R-manual/R-devel/library/stats/html/kmeans.html
- https://stat.ethz.ch/R-manual/R-devel/library/stats/html/princomp.html
